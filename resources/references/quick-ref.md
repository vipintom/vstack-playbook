# vstack Quick Reference

## Workflows
- `feature-delivery` — Multi-step new functionality
- `bug-fixing` — Defect repair with regression test
- `refactoring` — Structure improvement, behavior preserved
- `research` — Technical investigation
- `infrastructure` — Ops/infra changes
- `documentation` — Docs work
- `debt` — Code quality improvement

## Roles
- **Lead** — Delivery ownership, coordination, delegation
- **Builder** — Implementation, debugging, testing, evidence
- **Reviewer** — Independent assessment, findings, re-review

## Plugin Tools (when available)
- `vstack_status` — Project/delivery/task status
- `vstack_memory` — Search/read/update project memory
- `vstack_history` — Query activity history
- `vstack_delivery` — Delivery CRUD
- `vstack_task` — Task CRUD, dependencies, ready
- `vstack_agent` — Dispatch, track agent sessions
- `vstack_check` — Discover, execute, record checks

## Commands
- `/vstack` — Help & status
- `/vstack-start` — Start delivery
- `/vstack-status` — Show status
- `/vstack-resume` — Resume delivery
- `/vstack-report` — Generate summary
