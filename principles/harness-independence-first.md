# Harness Independence First

**Rule.** The method outranks the tools.

Every skill works with files alone. Harness affordances make it cheaper, never possible.

**Trigger.** You are about to name a tool as required.

**Test.** Strip the harness: can the skill still be completed with a text editor and a shell? If no, the step is wrong.

**Failure mode.** A method that only runs in one editor dies when the editor changes.
